# Technical Terms: Semantic Content Chunking

These terms are used in the scripts and should be displayed as subtitles or callouts in the video.

| Term | Dev-Friendly Definition | Script Usage/Example |
| :--- | :--- | :--- |
| **Temporal-Textual Conversion** | The algorithmic process of estimating visual duration from written text. | "Solving the Temporal-Textual Conversion Problem." |
| **Time-Cost Algorithm** | The heuristic process of estimating visual duration from written text based on word weights. | "Our Time-Cost Algorithm weights dialogue differently." |
| **Audio-Visual Split** | Parallel processing of text for video generation and text-to-speech synchronization. | "Handling long speeches with an Audio-Visual Split." |
| **Semantic Units** | The smallest independent chunks of meaning (sentences, dialogue lines) used as building blocks. | "Splitting the text into atomic semantic units." |
| **Temporal Constraint** | The fixed duration limit (e.g., 8s) of generative video models. | "Working within the 8-second temporal constraint." |
| **Action Density** | The frequency of physical events in a text segment, used to calculate visual pacing. | "High action density requires faster cuts." |
| **Micro-Cliffhanger** | A split point designed to end on unresolved action to maintain engagement. | "Using micro-cliffhangers to bridge segments." |
