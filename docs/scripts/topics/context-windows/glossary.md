# Technical Terms: Context Windows & Management

These terms are used in the scripts and should be displayed as subtitles or callouts in the video.

| Term | Dev-Friendly Definition | Script Usage/Example |
| :--- | :--- | :--- |
| **Context Window** | The maximum number of tokens an LLM can process in a single request. | "The novel exceeds the 128k context window." |
| **Lost-in-the-Middle** | The tendency of LLMs to ignore or misinterpret information located in the middle of a large context. | "We avoid Lost-in-the-Middle by using retrieval." |
| **Tokenization** | The process of splitting text into numerical units for the model. | "Each chapter is roughly 5k tokens." |
| **Context Management** | The active orchestration of what data is kept, summarized, or discarded. | "Continuum Flow implements context management." |
| **Semantic Retention** | Keeping information based on meaning rather than position. | "We use semantic retention to lock character traits." |
| **Context Rot** | The degradation of information quality as more tokens are added to a model's context. | "Preventing context rot in long narratives." |
| **RAG** | Retrieval-Augmented Generation; fetching relevant data from an external database at runtime. | "RAG vs. Hierarchical Summarization." |
