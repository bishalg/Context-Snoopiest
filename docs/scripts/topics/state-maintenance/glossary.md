# Technical Terms: State Maintenance & CCMS

| Term | Dev-Friendly Definition | Script Usage |
| :--- | :--- | :--- |
| **CCMS** | Character Consistency Maintenance System; the logic that prevents identity morphing. | "Running the CCMS check on Segment N." |
| **Character Drift** | The loss of visual identity across multiple generated clips. | "Reducing character drift in long-form video." |
| **Identity Vector** | A visual/numerical embedding that locks a character's features. | "Injecting the identity vector into the diffusion prompt." |
| **Master Reference** | Synthetic images generated during pre-production to serve as visual 'Ground Truth'. | "Generating Master References in Phase 1." |
| **State Machine** | A model where the system's behavior is determined by its current internal state. | "The novel as a state machine." |
| **Implicit Context** | Facts that are true based on past events but not mentioned in current text. | "Handling implicit context through state updates." |
| **Embedding Anchor** | A high-weight token or vector used to force the model to focus on a specific feature. | "Anchoring the character's scar in the prompt." |
