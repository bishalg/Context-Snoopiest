# Technical Terms: Narrative Semantic Compression

| Term | Dev-Friendly Definition | Script Usage |
| :--- | :--- | :--- |
| **Narrative AST** | Abstract Story Tree; a structured representation of the story elements. | "Walking the Narrative AST." |
| **Semantic Compression** | Reducing data volume by discarding non-functional or non-visual details. | "Applying semantic compression to Chapter 5." |
| **RepoMix Pattern** | Retaining definitions and signatures while stripping implementation logic. | "The RepoMix pattern for novel-to-video." |
| **SceneGraph** | A technical manifest mapping entities to visual parameters in a 3D/video space. | "Generating the SceneGraph from MD." |
| **Visual Signature** | The minimum set of descriptors required to maintain character/location identity. | "Every entity has a unique visual signature." |
| **Context Guard** | A module that ensures the prompt doesn't exceed the token budget. | "The Context Guard runs pre-generation." |
